# Nutation

[English](./README.md) | **简体中文**

Nutation是一款为阅读而生的浏览器翻译扩展。它支持多种语言和多个AI模型，翻译迅速、准确，同时只处理实际阅读的部分(不包含导航等元素).

`任意语言` · `任意模型` · `快` · `准` · `成本低` · `完全隐私`

## 为什么选择 Nutation

- **高效**：多标签同时处理，页面滚动时动态翻译新内容，重复内容立即显示(通过缓存),因为只翻实际阅读的部分,部分语言快速切换不用模型翻译比如中文简体繁体,绝大多数情况浏览时采用母语往往快得多.
- **更准**：不用再忍受chrome等自带低质量翻译。
- **省钱**：只翻实际阅读的部分，保留已有翻译，并可自由选择高性价比模型。
- **不被服务商绑定**：所有常见模型服务商和模型路由.
- **隐私默认留在本地**：你的API Key 和翻译缓存只保存在浏览器本地；网页文本只发送给你选择的模型。
- **支持页面总结**：快速获取关键信息.
- **复制元信息**：一键复制翻译后的标题、描述和链接,适合做笔记等场景。
- **打开即翻译**：配置后,按域名等规则自动翻译你常看的网站。
- **高度可配置**：服务商、模型、目标语言、翻译模式、摘要位置、缓存上限和自动翻译规则都可以自定义。
- **体验不变**：翻译前后官网体验完全一致，只有文本被替代。

## 快速开始

1. 安装 Nutation（见下方“安装”）。
2. 打开扩展的 **设置**。
3. 选择服务商，填写对应的 **API Key**（请自行从供应商获取）。
4. 填写模型，并设置默认目标语言。
5. 点击 **保存设置**。
6. 打开任意网页，点击工具栏中的 Nutation 图标。
7. 点击 **翻译**；需要恢复原文时点击 **恢复**。

## 支持的服务商

| 类型       | 服务商                                                   |
| ---------- | -------------------------------------------------------- |
| API 网关   | OpenRouter、Vercel AI Gateway                            |
| 直连服务商 | OpenAI、Anthropic、Google Gemini、DeepSeek、xAI、Mistral |
| 自定义     | 任意 OpenAI 兼容 `/chat/completions` 端点                |

> DeepSeek 需要先在设置中开启“允许将数据发送到中国境内服务商”授权后才会出现。

## 推荐模型（cost effective）

| 服务商            | 模型 ID                        | 说明                                                |
| ----------------- | ------------------------------ | --------------------------------------------------- |
| OpenAI            | `gpt-6-luna`                   | 速度快、成本低，适合日常网页翻译                    |
| DeepSeek          | `deepseek-v4.1-flash`          | DeepSeek V4.1 Flash，成本很低，适合长页面和批量文本 |
| OpenRouter        | `deepseek/deepseek-v4.1-flash` | 想用一个 Key 切换多家模型时使用                     |
| Vercel AI Gateway | `deepseek/deepseek-v4.1-flash` | 需要统一网关、额度或团队管理时使用                  |

模型 ID 请以服务商控制台实际显示的 ID 为准；不同网关的模型前缀可能不同。

推荐综合考虑以下因素：**性能**、**成本**、**准确度**和**实际体验**。

## 安装

暂不支持从商店直接安装（正在上架）。

### 离线安装

从 [https://dl.piaosiyuan.cn/Nutation/](https://dl.piaosiyuan.cn/Nutation/) 获取最新安装包；如果你是从源码运行，执行 `pnpm release` 后，同样的文件会生成在 `release/` 目录。

#### Chrome / Edge

2. 解压到一个固定目录，安装后不要删除该目录。
3. 打开扩展管理页：
   - Chrome：`chrome://extensions`
   - Edge：`edge://extensions`
4. 打开右上角的 **开发者模式**。
5. 点击 **加载已解压的扩展程序**，选择解压后的目录。

#### Firefox

临时加载：

1. 下载并解压 `nutation-firefox.zip`。
2. 打开 `about:debugging#/runtime/this-firefox`。
3. 点击 **临时载入附加组件**，选择解压目录中的 `manifest.json`。

> Firefox 正式版默认只允许安装已签名的扩展。临时加载会在浏览器重启后失效；

源码详细发布说明见 [RELEASE.md](./RELEASE.md)。
